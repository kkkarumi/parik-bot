# Анкета для запуска бота

Отправьте салону (или заполните вместе на встрече). Всё, что здесь есть, вносится при запуске, дальше владелец меняет сам через /admin.

## 1. Салон

| Что | Ответ |
|---|---|
| Название (как увидят клиенты) | |
| Юрлицо / ИП / самозанятый, ИНН (для оферты и политики ПДн) | |
| Адрес (как найти: этаж, вход, ориентир) | |
| Телефон для клиентов | |
| Часы работы (текстом, например «Пн–Сб 10:00–20:00») | |
| Instagram или другая ссылка на работы | |
| Часовой пояс (если не Москва) | |
| Приветствие в боте (1–3 предложения; можно оставить стандартное) | |

Длительность важна: по ней бот считает свободные окна. Если «примерно 40–60 минут» — ставим 60.

|---|---|---|---|
| | | | |

Пример графика: «Пн–Пт 10–20, перерыв 14–15; Сб 10–16; Вс выходной».

## 4. Правила записи

| Что | Ответ |
|---|---|
