# Продажа: что, кому, как

## Что продаётся
Готовый бот записи «под ключ»: свой бот салона с его названием, настроенные услуги, мастера и график, ссылка и QR-код. Плюс обслуживание: сервер, обновления, бэкапы, помощь.

**Цена:** 3000 ₽ запуск + 1500 ₽/мес обслуживание.

## Кому
Барбершопы, салоны красоты, мастера маникюра и бровей, массаж, автомойки и шиномонтаж (любая запись «мастер + услуга + время»).

## Сообщение для первого контакта
> Здравствуйте! Делаю для салонов Нальчика Telegram-бота для онлайн-записи. Клиент сам выбирает услугу, мастера и время, бот напоминает ему за день и за 2 часа, мастеру приходит уведомление. Меньше звонков и меньше неявок, а при желании предоплата по чеку.
> Вот как это выглядит: <ссылка на демо-бота>. Запишитесь на любое время, и всё увидите сами.
> Запуск 3000 ₽, дальше 1500 ₽ в месяц за сервер и поддержку. Настраиваю за один день.

## Демо-бот
Держите один бот с демо-данными (`./setup.sh` → ответить `y` на демо). Дайте человеку записаться, а сами покажите /schedule и /admin со своего телефона.

## Запуск для клиента (чек-лист)
1. Клиент создаёт бота в @BotFather (или вы с его телефона): имя «Барбершоп X | Запись», username, аватарка = логотип.
2. На сервере: `git clone … salon-x && cd salon-x && ./setup.sh`, затем вставить токен и название.
3. По ссылке из setup.sh зайти админом: услуги, цены, мастера, график, адрес, телефон.
4. Мастерам разослать ссылки-приглашения (/admin → Мастера → Подключить к боту).
5. /admin → Салон → «Передать админку»: ссылку владельцу. Отправить ему `docs/ИНСТРУКЦИЯ_ДЛЯ_САЛОНА.md`.
6. /admin → Ссылка и QR-код: отдать ссылку и QR для печати.
7. Добавить ежедневный бэкап в crontab (см. README).

## Что входит в 1500 ₽/мес
Сервер, мониторинг, бэкапы, обновления (`./scripts/update.sh`), правки по просьбе: новые услуги, тексты, помощь мастерам.
